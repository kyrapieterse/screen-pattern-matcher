# Multi-panel pattern matcher

Compare a continuous pattern with a repeat that starts again at each panel edge. This free browser tool works offline and processes files on your device.

## Run locally

Download the repository as a ZIP, extract it and open `index.html` in a modern browser. No build step, account or API key is required.

## Try the example

Start with three panels at 650 mm, joints at 30 mm and a 240 mm tile. The run is 2,010 mm. Compare the pattern at the second panel in the two rows, then change the offset. Save the PNG to compare both rows away from the tool.

## How it works

The upper row uses coordinates measured from the start of the whole opening. The lower row measures from each panel’s own left edge. The solid border clips the design on all four sides. Uploaded tiles keep their native aspect ratio.

For related examples and project guidance, see the [Tint & Screen screen pattern library](https://tintandscreen.co.za/architectural-screens/patterns/).
